# Android Java Instagram Clone

This project is a basic Instagram clone built with Android (Java) and Firebase.
It allows users to register, sign in, upload posts with images and view a simple
feed. The repository contains Android Studio project files.

## Setup
1. Clone the repository.
2. Copy `app/google-services.example.json` to
   `app/google-services.json` and fill it with your Firebase project
   credentials.
3. Open the project in Android Studio and let Gradle sync the
   dependencies.

## Features
- Firebase Authentication for sign‑in and sign‑up
- Upload images to Firebase Storage and store post data in Firestore
- Display posts in a RecyclerView

## Development
Example unit and instrumentation tests are located under
`app/src/test` and `app/src/androidTest`.

Feel free to fork and extend the project.
